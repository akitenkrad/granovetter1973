# The Strength of Weak Ties — Granovetter (1973)

A reimplementation of Mark Granovetter's classic *The Strength of Weak Ties* (*American Journal of Sociology* 78(6), 1360–1380). The 1973 paper is conceptual and has no controlled experiment, so this project **operationalizes its hypotheses into a measurable agent-based model**: a clustered network of dense **strong-tie** communities sparsely connected by **weak-tie bridges**, plus an information-diffusion process (SI / threshold cascade) on top of it. It measures the paper's structural propositions ("all (local) bridges are weak ties", the rarity of the forbidden triad) and reproduces the headline result that **weak ties dominate reach**: removing the weak ties collapses diffusion to the seed's own cluster, whereas the strong ties alone cannot bridge clusters at all.

Tie strength is stored as the **edge weight** of a weighted undirected `socsim-net` network (`WeightedNetwork<TieStrength>`), not in a side-table — this resolves the design's UNCONFIRMED side-table workaround thanks to socsim issue #18 (weighted edges) and #20 (local-bridge / path-length analysis helpers). The simulation is written in Rust on top of the [socsim](https://github.com/akitenkrad/rs-social-simulation-tools) framework, and the visualization tools in Python.

> The threshold cascade borrows its formulation from Granovetter (1978) *Threshold Models of Collective Behavior*; the 1973 paper itself is conceptual. See [Architecture](docs/architecture.md).

## Install & Quick start

```bash
# Build the Rust simulation
cargo build --release

# Run the weak-tie bridging network + SI diffusion (default-ish settings)
cargo run --release -- run --clusters 10 --cluster-size 20 \
    --p-strong 0.6 --p-bridge 0.3 --diffusion si --beta 0.5 --seed 42

# Weak-tie ablation: removing weak ties collapses reach to one cluster
cargo run --release -- ablation --remove weak \
    --clusters 10 --cluster-size 20 --p-bridge 0.5 --beta 0.9 --runs 10 --seed 42

# Install the Python visualization tools (at the workspace root)
uv sync

# Visualize the most recent run (network layout + metrics)
uv run granovetter-tools visualize

# Reproduce the paper's headline claims in one command (PASS/off verdicts + figures)
uv run granovetter-tools reproduce
```

## Scope

This repository implements the clustered weak-tie bridging network generator, the SI / threshold diffusion mechanism, and the paper's structural propositions, exposed through four Rust subcommands — `run` (one network + diffusion), `ablation` (weak / strong / random edge removal, the paper's headline result), `sweep` (parameter sweeps), and `reproduce` (a one-shot reproduction of the headline quantitative claims with observed-vs-expected PASS/off verdicts) — plus the Python `granovetter-tools` (`visualize` / `visualize-sweep` / `show-experiment-settings` / `reproduce`). See the [CLI](docs/cli.md) and [Visualization](docs/visualization.md) docs.
